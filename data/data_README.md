# Data

## real_merchants.csv
Training data for the spending categorizer. Columns: description (bank statement style text), category (team category), brand (the merchant). Generated by src/generate_merchants.py. To add merchants, edit the BRANDS lists in that script, run py src/generate_merchants.py, and commit the new CSV. When testing, split train and test by brand.

## sample_transactions.csv
2,000 row sample of the Kaggle dataset "Credit Card Transactions Fraud Detection Dataset" (kartik2112). Columns: merchant, category (Kaggle label), team_category, amt, is_fraud. The merchant names in this dataset are simulated, so use it for the unusual transaction detector (amounts), not for categorization.

## label_mapping.csv
Maps Kaggle category labels to team categories.

## sample_student_transactions.csv
Sample student bank transaction dataset containing 30 transactions within the last month for a college student at the University of Florida (UF). Contains no sensitive banking information. Descriptions match real merchants from `real_merchants.csv` (e.g., Publix, The Standard, GRU, Gator Dining, UF Bookstore, The Swamp Restaurant). Generated and cleaned by `src/data_cleaning.py`.

The full Kaggle file (fraudTrain.csv) is not stored in the repo. Download it from Kaggle.
